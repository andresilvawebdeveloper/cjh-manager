# Procedimento em caso de Violação de Dados Pessoais (arts. 33.º e 34.º RGPD)

Uma **violação de dados** é qualquer incidente que leve à destruição, perda, alteração, divulgação ou acesso não autorizado a dados pessoais. Exemplos: telemóvel de um treinador perdido sem bloqueio e com a app aberta; password de treinador partilhada ou roubada; vídeos de atletas partilhados por engano; base de dados acessível sem regras de acesso.

## Passo a passo
| Quando | O quê |
|---|---|
| **Imediatamente** | Conter: mudar a password da conta afetada (Supabase → Authentication → Users), terminar sessões, revogar links partilhados, apagar publicações indevidas. |
| **Até 24 h** | Registar o incidente na tabela abaixo: o que aconteceu, que dados, quantos atletas, desde quando. Avisar o responsável do clube. |
| **Até 72 h** depois de ter conhecimento | Se houver **risco** para os atletas/famílias, **notificar a CNPD** (formulário em www.cnpd.pt → "Notificação de violação de dados"). Se ainda faltar informação, notificar na mesma e completar depois. |
| **Sem demora** | Se o risco for **elevado** (ex.: vídeos ou dados de menores expostos publicamente), **informar as famílias afetadas** em linguagem clara: o que aconteceu, consequências prováveis, medidas tomadas e contacto. |
| **Depois** | Corrigir a causa e rever este procedimento. |

**Não é necessário notificar a CNPD** se for improvável que o incidente gere risco (ex.: telemóvel perdido mas bloqueado com código e a app sem sessão aberta). Mesmo assim, **registar sempre** o incidente.
